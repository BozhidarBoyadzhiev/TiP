## 3. Break the guards

Each guard was broken one at a time in the smallest realistic way. The relevant test classes then ran through `./gradlew test --offline --tests ...`, or `pio test -e native` for the firmware. After each run the file was restored with `git checkout -- <file>` and `git status --porcelain` was checked: it was empty after every one of the 64 runs and at the end. Line numbers are on the clean tree. "Caught" means at least one test failed on an assertion about the broken behaviour. No run hit a compile error or an unrelated failure.
